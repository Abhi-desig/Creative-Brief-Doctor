Drop one real brief per file here, `.md` or `.txt`.

The filename (minus extension) becomes the brief id in the CSV, so name them
meaningfully — `01-launch-vague.md`, `07-rebrand-detailed.md`.

Aim for 20, spanning the range you actually receive: a couple that are genuinely
good, a couple that are near-empty, and the ordinary middle. A set of uniformly
mediocre briefs compresses the score range and makes the ordering statistics
meaningless.

Brief contents are NOT committed — `.gitignore` excludes everything in this
directory except this file. Read the free-tier data-use terms before pasting
client-confidential material into the Gemini free tier.
